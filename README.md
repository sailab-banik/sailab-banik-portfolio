# sailab-banik-portfolio

Personal portfolio for Sailab Banik — a single page with a downloadable resume.

Built with Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS v4.

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```
