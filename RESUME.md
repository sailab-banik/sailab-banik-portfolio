# Resume — Working Guide

This file is the source of truth for improving `sailab-banik-resume.tex`.
Anyone (or any AI assistant) editing the resume in this repo should read this first,
work through the checklist, and tick items off as they land.

**Target:** Software Engineer / AI Engineer roles (LLM systems, RAG, full-stack Python + React), ~3 YOE.
**Format rule:** one page, single column, no graphics.

---

## Ground rules (do not break these)

1. **Never invent numbers.** Any metric not already in the `.tex` must come from Sailab.
   Use `[TODO: …]` placeholders instead of guessing.
2. **Never commit the real phone number.** The `.tex` uses a masked `\phone` macro;
   `build.sh` injects the real one from `phone.local` (gitignored). Anything under
   `public/` is served publicly.
3. **Stay on one page.** Two pages is advice for 5+ YOE. If something new goes in,
   something weaker comes out.
4. **Plain, human wording.** Hiring managers discount resumes that read as AI-polished.
   Avoid stacked em-dashes, "from the ground up", "*and*"-style emphasis, and vague
   flourishes. Short, direct verbs.
5. **Every metric must be defensible in an interview.** If there's no measurement,
   describe the concrete practice instead of a percentage.
6. **Don't claim a skill the bullets can't back up.** Skills listed only in the Skills
   section should either appear in a bullet or be removed.

---

## Target section order

1. **Header:** name, location, phone (masked macro), email, portfolio, LinkedIn, GitHub, Medium
2. **Summary:** 2–3 lines under a `SUMMARY` heading, no links. It was run without the heading for a while; the paragraph read as stray text between the header and Work Experience, so the heading is back.
3. **Work Experience**
4. **Projects**
5. **Technical Skills**
6. **Education**
7. **Awards & Certifications**
8. **Spoken Languages:** one line, optional; drop it first if the page overflows

Why: at ~3 YOE, experience is the strongest evidence and should be the first thing a human reads.
ATS doesn't care about order, so this is purely for the recruiter's skim.
